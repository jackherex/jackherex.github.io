这个测试页在验证什么

  1. 滚动驱动动画——全部用 CSS animation-timeline: view()，没有一行滚动监听 JS；不支持的环境自动静态呈现。
  2. 海报墙 3D 展平——静止时整面墙就是倾斜的（perspective(2400px) + rotateX 18°），往下滚从 26° 慢慢正到 8°；墙的上下左右四边都有渐变遮罩，不会被视口切出直角断层。
  3. 两层位移叠加——外层每行跟着滚动进度做反向滑（--row-shift 取反），内层轨道永不停地在横向漂移（--marquee-duration 110~132s）。两层各走各的，所以滚动时墙在动，停住时墙也在动。
  4. Hero 上移淡出——第一屏滚到 40% 开始上移 80px、缩到 0.92 并淡出，把位子让给后面的墙。
  5. 逐行错峰——标题一行一行进，桌面端还带 blur(8px) 从模糊到清晰；卡片按 --reveal-delay 排队归位。
  6. 桌面专属离场——仅 768px 以上，区块滚远时淡到 0.3 并上移 28px，页面不会堆着一屏旧内容。
  7. 徽章行 + 产品化 mock——「免费 / 无广告 / 三端」提到第一屏；观影统计和榜单做成控制台样子。
